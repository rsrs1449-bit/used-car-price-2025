# 🚗 Used Car Price Prediction App

تطبيق ويب مبني باستخدام **Streamlit** لتوقع سعر السيارة المستعملة اعتمادًا على مجموعة من الخصائص مثل سنة الصنع، الممشى، نوع السيارة، الوقود، المدينة وغيرها.

---

## 🎯 فكرة المشروع
يهدف هذا المشروع إلى مساعدة المستخدمين في **تقدير السعر المتوقع للسيارات المستعملة** باستخدام تقنيات تعلم الآلة، مما يسهل اتخاذ قرارات الشراء أو البيع.

---

## 🧠 النموذج المستخدم
- تم تدريب نموذج تعلم آلي باستخدام بيانات سيارات مستعملة.
- النموذج محفوظ بصيغة `model.pkl`.
- يعتمد على **Scikit-learn Pipeline** لدمج المعالجة المسبقة مع النموذج.

---

## 📊 الخصائص المستخدمة في التوقع
- سنة الصنع  
- الممشى (كم)  
- سعة المحرك  
- عدد السلندرات  
- الماركة  
- نوع السيارة  
- نوع القير  
- نوع الوقود  
- المدينة  
- حالة السيارة  
- اللون  
- عدد الملاك السابقين  
- وجود حوادث  
- وجود ضمان  

---

## 🖥️ واجهة المستخدم
- واجهة تفاعلية باستخدام Streamlit
- Sliders و Selectbox لإدخال البيانات
- عرض السعر المتوقع مباشرة
- تنظيم المحتوى باستخدام Tabs
